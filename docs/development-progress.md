# Moviloq 开发进度：运输规划与草稿

本阶段实现可以操作并持久保存的运输草稿，不代表正式交易系统已经完成。首发方向仍是法兰克福、自助撮合、英文和中文。

## 已实现

- 1 个提货点、1–20 个送达点，可添加、移除、调整顺序。
- 联系人/电话/门禁备注选填；货物名称、件数、总重量、最大单件尺寸、易碎标记。
- 六档车型，总重量和保持直立的最大单件尺寸校验。暂不计算整批货物装箱率。
- 即时意向/预约意向；预约为未来 15 分钟至 30 天，按设备时区输入、UTC 保存。
- 分项试算、10 分钟估价期限、修改后重新估价；价格和 VAT 均为开发演示规则，非商业承诺。
- 草稿创建、列表、恢复、修改、删除；服务器重新校验和计价。
- 浏览器隔离的访问 Cookie、数据库哈希、同源写入检查、请求大小及频率限制、重复创建保护、原子版本冲突检查。
- 首次保存起 30 天的空间有效期，每空间最多 30 份；生产定时清理、手动删除。
- Cloudflare D1 欧盟辖区数据库；每个 PR 独立数据库、迁移、发布后测试和关闭后清理。
- GitHub 质量检查、API 写入测试和 Chromium 浏览器流程测试；生产发布只运行不创建草稿的冒烟检查。

## 使用与限制

入口为 `/book` 和 `/drafts`。草稿属于当前浏览器及当前网站地址；根域名与 www 不共享 Cookie。不是注册账户，清除 Cookie 后无法找回，也没有跨设备同步。上线前请使用示例资料。

保存不等于下单，不会发布给司机，不收款，不构成运输合同。当前手填里程，未接入地图地址搜索、真实导航、服务区判断。页面已有中英文数据保存说明，完整隐私政策仍待注册主体及专业审核。
