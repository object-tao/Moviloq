# 预约运输：国家与城市选择

本次调整仅改变预约草稿的地点录入，不开通正式接单或跨境计费。

- 提货点及全部送达点先选择国家，再从该国城市列表选择城市；切换国家清空原城市。
- 新草稿默认国家为德国，城市须用户主动选择。新增站点、排序、语言切换及草稿重开保留各站点的结构化地点。
- 详细地址放在可展开的选填区域，城市级路线可以估价并保存草稿。
- `shared/locations.ts` 维护首批 12 个国家的常用城市，包含德国、波兰、西班牙等；这不是完整欧洲地名库，也不是服务覆盖承诺。
- 国家保存 ISO 代码，城市保存稳定英文值；界面和草稿摘要支持中英文。服务端校验城市所属国家，不能通过伪造请求绕过。
- 原有地址型草稿可继续读取，不猜测城市、不覆盖原地址和历史估价。再次保存前需补选国家与城市；无须数据库迁移。
- 地图及自动道路里程尚未接入，测试估价仍仅支持手填 1–500 公里。未扩展价格规则、长途计价、车型或运营服务范围。

验证：单元/API 测试覆盖地点组合、城市级保存和旧草稿兼容；`scripts/browser-smoke.mjs` 覆盖联动、排序、保存/重开、双语及移动布局；`scripts/drafts-smoke.mjs` 覆盖真实本地 D1 CRUD 和权限隔离。
