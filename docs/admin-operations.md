# 后台第一批：运营准备版

本批按用户于 2026-09-13 确认的范围开发。入口为 [admin.moviloq.com](https://admin.moviloq.com)。使用原自有账号密码登录；保留初始密码强制修改，不引入邮箱验证码或 MFA。

## 已实现的操作

| 模块 | 可用功能 |
| --- | --- |
| 工作台 | 真实车队/司机/车辆数量、资料就绪数量、审核与补件待办、未来 30 天及过期资料提醒 |
| 车队、司机、车辆 | 新增、查询、分页、编辑、来源与授权标记、车队关系、车辆容量与设备资料 |
| 审核 | 提交、通过、退回补件、拒绝、暂停、恢复至待审；编辑通过的档案会重新进入审核 |
| 资料附件 | 私密 PNG/JPEG/PDF 上传、预览/下载、审核、有效期、重交留旧版本、访问审计 |
| 司机车辆配对 | 同车队、有效资料与匹配车型检查，配对/解除，历史留痕，一名司机不能同时配对两辆车 |
| 服务规则 | 法兰克福范围、营业说明、车型容量、当地确认的资料清单 |
| 定价 | 起步费、两段里程费、额外站点、装卸、搬运人员、等候和优先费用、工程税率；保存、试算、定时/立即发布 |
| 配置版本 | 发布后不可覆盖修改；复制旧版成为新草稿，可重新发布以恢复旧规则 |
| 内容 | 中英文 FAQ、公告、服务说明，纯文本预览和发布；发布内容展示在客户网站帮助页 |
| 员工 | 创建运营/审核员、修改角色、停用、撤销会话、重置临时密码；平台所有者受保护 |
| 审计 | 业务变更、审核、配对、发布、文件读取及员工权限变更；后台不提供修改或删除日志入口 |

首次发布没有导入真实合作方资料、创建实际员工、发布商业费率或主动发送外部通知。后续已按用户明确要求添加带「演示 DEMO」标记的草稿车队、司机和车辆；这些示例不是已核验运力，也不包含模拟收入或真实订单。

## 推荐使用顺序

自 2026-09-14 起，后台菜单按资料维护和审核职责分组：

- 合作车队 → 车队列表。
- 司机管理 → 司机列表。
- 车辆管理 → 车辆列表。
- 审核管理 → 审核总览、车队审核、司机审核、车辆审核。

一级菜单可点击或通过键盘展开/收起。档案列表负责新增、修改、上传资料和提交审核；通过、退回补件、拒绝、暂停及恢复集中在独立的审核详情页。车队、司机、车辆审核分别筛选对应档案和附件，并提供待审、补件、通过、拒绝、暂停与到期筛选。档案与附件独立分页。

草稿不会自动出现在待审核队列，包括此前按用户要求添加的 3 个车队、6 位司机、6 辆车辆的演示档案；须先明确提交审核。示例资料不代表实际资质，不能仅为演示而审核通过。

车队、司机、车辆列表右上角分别提供新增弹窗：保存为草稿后返回列表，服务器校验失败时保留填写内容；可取消或按 Esc 关闭。保存中禁止重复提交；网络结果无法确认时提示先检查列表，不自动重试。没有脚本支持时，同一入口仍可打开完整新增页面。

三类列表最右侧为固定操作列：「编辑」打开资料维护页；车队的「审核编辑」打开独立审核页，司机和车辆使用审核弹窗。运营角色显示「编辑 / 查看审核」，审核员显示「查看 / 审核编辑」，权限继续由服务器控制。

审核详情及失败提示按实时数据逐项显示未满足条件，并提供对应处理入口：授权未确认、审核清单未发布或未生效、必要附件未上传/待审核/需补件/过期、所属车队未就绪、司机配对不匹配。没有已生效清单时不会擅自指定证件类型，而会显示当前附件数量并引导先配置清单。清单入口按当前档案类别或车型筛选，保留既有草稿和定时发布版本；发布仍需管理员确认。

司机、车辆弹窗中的处理入口在新标签页打开，保留原审核原因；补齐后关闭并重新打开审核弹窗，加载最新资料后再提交。审核员无权配置清单时显示联系管理员的提示，不提供越权入口。提示优化不自动发布清单、上传附件或审核通过示例档案。

1. 使用原管理员账号登录；如提示首次改密，先设置独立新密码。
2. 在「服务与规则 → 新建配置」选择「审核清单」，为车队、司机和实际使用的车型分别设置必需资料，勾选当地负责人确认后保存、发布。清单未发布时不能通过档案审核。
3. 在车队页面录入已获授权的合作车队资料。建档不创建登录身份，也不自动联系合作方。
4. 上传必要资料并在档案详情「提交审核」，进入「审核管理 → 车队审核」，先审核文件，再在独立档案审核页执行「审核通过」。
5. 录入司机与车辆，关联车队，按同样步骤审核。对已就绪的车辆选择合格司机并保存配对。
6. 需要协作时，在「员工与权限」创建受限账号。通过你认可的私密渠道交付临时密码；员工首次登录必须改密。
7. 新建价格草稿并试算。明确确认工程估价用途后发布；正式经营价格与交易上线仍需另行确认。

「资料就绪」只表示当前授权、审核清单、有效文件及关联资料满足准备条件，不代表已开通司机账号、已经在线、可以真实接单或法律资质获得平台保证。

## 权限边界

- 管理员：全部本批操作，包括规则发布和员工管理。
- 运营：查询/维护资料、上传附件、配对、配置草稿；不能审核通过资料、发布规则或管理员工。
- 审核员：查看资料、审核文件与档案、暂停与恢复至待审；不能改价、编辑合作资料或管理员工。
- 以上权限在服务端执行，不只靠隐藏菜单。司机和车队成员不是这些平台员工角色。
- 变更员工权限/状态、重置密码会撤销该员工全部旧会话。不能停用自己或通过这些入口修改平台所有者。

## 客户网站的最小联动

- `/api/quotes` 与草稿保存读取当前生效的价格规则，服务器计算金额。
- 新估价带价格版本和规则快照；已保存草稿不会被后台发布操作批量改价。客户主动编辑并保存草稿仍会重新估价。
- `/api/vehicles` 与运输规划页读取已发布的车型容量，服务器保存时再次校验；停用车型不能用于新估价。
- 后台发布的内容由 `/api/content` 提供，仅包含已生效公开内容，展示在帮助页。未发布资料、合作方档案与附件不会公开。
- 无已发布费率时保留明确标注的原工程样例估价，不将它解释为商业报价。
- 区域配置中的启用开关可以暂停新估价；半径、中心点与营业说明仅为后续服务区校验准备，当前没有真实地图验证或营业时段自动拦截。

## 存储、并发与附件限制

- `ADMIN_DB` 继续只存认证、权限和员工安全事件；`OPS_DB` 绑定现有欧盟业务 D1，新增 `ops_*` 准备数据表。
- 初始 `driver_profiles` 需要真实用户身份，因此本批使用独立准备档案，不为录入的司机伪造客户/登录账户。第二批开通合作端时需显式关联经确认的身份。
- 后台服务只提供受控业务操作，没有客户私人草稿查询入口，也不对浏览器开放 SQL 或 Cloudflare 密钥。
- 表单记录版本防止旧页面覆盖新数据；全局业务修订号与 D1 原子批次保护跨档案、文件、审核清单与配对检查。冲突返回 409，不进行部分修改或生成虚假成功日志。
- 配置发布和文件重交使用单调序号消除同毫秒提交的排序歧义。
- 第一批附件使用私有 D1 二进制存储，PNG/JPEG 可预览，PDF 强制下载；不创建公开存储桶或开通新收费服务。
- 每份附件最多 512 KiB，每个档案最多 20 份（含历史版本），合计 50 MiB。需更多容量或原始大扫描件时再迁移到私有对象存储；不自动删除旧证据腾空间。
- 附件必须通过大小、类型和文件头检查，但这不是杀毒扫描。只接收可信合作来源，下载 PDF 仍应使用更新的阅读器。
- 附件需填写有效至日期；无外部到期日期时填写当地负责人确定的内部复核日期。有效期按 UTC 日期检查。
- 关联下拉最多显示 500 条候选档案；员工最多 100 个；超过准备阶段规模前需增强搜索/存储和权限设计。
- 到期与缺件提醒来自实时数据查询，不依赖定时任务成功；站内待办已实现，邮件/短信尚未配置或发送。

自动测试覆盖实际 SQLite SQL、审核状态、资料重交/过期、配对限制、版本冲突、权限、CSRF、员工会话撤销、报价快照及客户端 API 联动。浏览器测试使用独立的本地 workerd、D1 和随机测试凭据，不在生产创建演示车队、文件或订单。

数据库迁移为新增表/字段，不删除现有草稿、账号或订单表。回退前应先评估：旧版认证代码不理解新增员工角色，不能直接把后台回退到不执行角色控制的版本并继续开放。紧急情况优先关闭后台业务绑定/入口，并保留本批身份权限控制，再进行受控修复；不要回滚或删除已产生的审核和审计资料。
